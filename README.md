# java-racingcar-precourse - [BE] 조상준

## 1. 어플리케이션 정의

| 한글 | 영문 | 설명 |
| --- | --- | --- |
| 경주 | race | 전체 게임을 의미한다. |
| 라운드 | round | 경주 속 한 횟수 단위를 의미한다. |
| 시도 횟수 | attempt count | 각 라운드의 수를 의미한다. |
| 무작위 값 | random number | 전진 여부를 결정하는 무작위 난수 값을 의미한다. |
| 자동차 | car | 경주에 참여하는 자동차 하나를 의미한다. |
| 우승자  | winner | 전체 게임의 우승자를 의미한다. 우승자는 가장 멀리 이동한 자동차를 의미한다. |
| 전진 상태 | progress status | 자동차의 전진 상태를 의미한다. 어플리케이션 내부에서 ‘-’로 표현한다. |
| 이동 거리 | position | 현시점의 자동차가 이동한 거리를 의미한다. |

## 2. 기능 명세 🎯

- 해당 어플리케이션은 `사용자 흐름`이 아닌 `기능 단위 중심`으로 명세 되었습니다.

### 🚗 사용자 입출력 단계

- [ ] 사용자는 경주할 자동차 이름들을 입력한다. (쉼표 구분)
- [ ] 사용자는 시도할 라운드 횟수를 입력한다.
- [ ] 각 라운드의 실행 결과를 출력한다.
    - 형식: `{자동차이름} : {전진상태}`
- [ ] 최종 우승자를 출력한다.
    - 형식: `최종 우승자 : {이름1}, {이름2}, ...`

### 🚗 입력 문자열 파싱

- [ ] 자동차 이름 문자열에서 쉼표를 기준으로 이름을 추출한다.

### 🚗 출력 문자열 포멧팅

- [ ] 각 자동차 이름과 이동 상태를 문자열로 변환한다.
    - 예시: `pobi : -`
- [ ] 우승자 리스트를 문자열로 변환한다.
    - 예시: `최종 우승자 : pobi, jun`

### 🚗 자동차 경주

**전체 게임 조율**

- [ ] 전체 라운드를 진행한다.
- [ ] 모든 라운드가 종료되면 우승자를 선별한다. 우승자는 1명 이상일 수 있다.
- [ ] 경기 결과를 반환한다.

**라운드**

- [ ] 각 자동차에게 무작위 값을 부여한다.
    - 0~9 사이의 무작위 값을 부여한다.
- [ ] 무작위 값을 바탕으로 전진 여부를 판단한다.
- [ ] 전진 조건(4 이상)을 만족하는 자동차를 전진시킨다.

**자동차**

- [ ] 전진 명령을 받으면 1칸 이동한다.

### 🚗 검증

- [ ] 시도할 횟수 숫자 입력값 검증
  - [ ] 숫자가 아닌 경우 `IllegalArgumentException` 이 발생한다.
  - [ ] 음수인 경우 `IllegalArgumentException`이 발생한다.
  - [ ] int형 범위를 벗어나는 경우 `IllegalArgumentException`이 발생한다.
- [ ] 자동차 이름 입력값 검증
  - [ ] 쉼표는 문자열의 맨 앞,뒤,혹은 연속으로 위치할 수 없다.
- [ ] 자동차 이름 단위 검증 (1개 단위)
  - [ ] 각 자동차 이름은 1자 이상, 5자 이하여야 한다.
  - [ ] 각 자동차 이름은 중복 될 수 없다.
  - [ ] 각 자동차 이름은 빈 문자가 될 수 없다.
  - [ ] 각 자동차 이름은 공백 문자열이 될 수 없다.
